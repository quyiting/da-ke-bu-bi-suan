# 大可不必算

一个原生微信小程序，主题是轻互动占卜与个人报告体验。

## 当前包含

- 首页：今日推荐、使用概览、今日气场、玩法路径、最近记录
- 抽签页：按主题和面对方式抽签，生成更个性化的签文和行动建议
- 六爻页：按问题类型起卦，按节气精确切月，生成月建、日辰、旬空、伏神、纳甲六爻盘、用神提要、本卦变卦与分享海报
- 星盘页：录入出生日期、时间、地点，生成轻量星盘、元素分布、宫位重心和人格解读
- 我的页：本地历史记录、筛选、统计摘要、使用画像、跨设备拉回、分开清空本机与云端
- 全局：底部 `tabBar` 导航

## 打开方式

1. 打开微信开发者工具
2. 选择“导入项目”
3. 项目目录选择当前文件夹
4. `AppID` 没有正式号时可先使用测试号或开发者工具提供的体验方式
5. 导入后直接预览页面结构和本地交互

## 云开发接入

这一版已经把“静默识别用户 + 云端保存历史记录 + 我的页显示账号状态”的正式版接进去了，但默认还是安全的本地模式。要真正开启云端同步，按这个顺序做：

1. 在 `utils/cloud.js` 里把 `CLOUD_ENV_ID` 改成你自己的云开发环境 ID
2. 在微信开发者工具里开通同一个云开发环境
3. 右键 `cloudfunctions/account` 和 `cloudfunctions/historySync`，分别执行“上传并部署：云端安装依赖”
4. 确认云数据库里已经创建或自动生成 `fortune_users`、`fortune_history_snapshots` 两个集合
5. 重新编译后，到“我的”页看账号与同步状态卡片

## 记录与同步说明

- `立即同步`：把当前设备上的记录和云端备份对齐
- `从云端拉回`：把当前账号云端保存的历史重新拉到这台设备
- `清空本机`：只清空当前设备，不动云端，而且之后不会自动回灌，必须手动点“从云端拉回”
- `清空云端`：只清空当前账号在云端的历史备份，本机记录保留
- `恢复云端备份`：在清空云端之后，手动把本机记录重新上传成新的云端备份
