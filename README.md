# 大可不必算

一个原生微信小程序，定位为免费的传统文化娱乐与自我复盘体验。

核心流程：**抽签或六爻问事 → 查看简明结果 → 自动保存到本机 → 回看完整结果 → 更新回访或分享海报**。

## 当前开放功能

- **首页**：今日一签卡片、主题抽签、六爻问事；也可以选择预设问题，查看最近结果与本机使用统计。
- **今日一签**：按本机日期固定一支自我整理签，当天重复打开显示相同完整内容；首次揭签才保存记录。
- **主题抽签**：选择主题和面对方式，先读签文、一句提醒与行动建议；其余解读按需展开。
- **六爻问事**：分类、问题引导、六次投币逐爻展示、本卦与变卦、简明解读，以及按需展开的详细卦盘。动画约1.8秒，可跳过。
- **卦象小知识**：64卦均可查看卦名、卦序、《周易》卦辞原文和本项目编写的白话提示，默认折叠。
- **本机记录**：列表优先展示，统计默认折叠；支持筛选、完整结果回看、单条删除和容量提醒。
- **六爻回访**：标记待回看、部分应、已应或暂未应；支持最多200字的回访备注、编辑与清空，记录页和原卦页同步。
- **分享海报**：抽签与六爻结果都可以生成海报，保存到相册或长按图片分享。

当前体验不需要注册或填写出生信息，默认使用微信本地存储。

## 使用方式

1. 用微信开发者工具导入本目录。
2. 配置你有权限使用的小程序 AppID。
3. 编译后，从首页选择“今日一签”“主题抽签”或“六爻问事”。
4. 生成结果后，打开“记录”查看历史。

本项目直接使用微信小程序运行环境，没有独立 Web 服务或前端 npm 构建步骤。

## 本地记录规则

- 今日一签按本机日期生成，日期相同则内容相同；再次回看不新增记录。返回今日签页面时会检查日期，跨天后可揭开新签。
- 当天签文另外保留一份本机缓存。删除或清空历史记录不会重置当日签文，回看也不会自动恢复已删除的历史；清理小程序全部数据后缓存会一并清除。
- 今日一签首次保存也遵守20条上限及满额确认；主题抽签可以针对不同问题重新生成。
- 起卦动画使用同一次生成的六组铜钱，跳过不会重新起卦；动画未完成时离开页面会取消，不在后台新增记录。
- 新结果保存完整内容，而不只保存摘要。
- 回看使用当时的结果，不会重新抽签或起卦，也不会新增记录。
- 当前最多保留20条，按最近创建或回访更新时间排序；剩余两条位置时，记录页显示提醒。
- 满额后再次抽签或起卦，会先询问是否替换最久未更新的记录，并展示该记录标题；取消不会生成新结果或删除旧记录。
- 单条删除需要确认，删除后会刷新当前筛选、统计和剩余容量，其他记录不受影响。
- 回访备注最多200字，点击保存才会写入本机；留空保存可清除备注，修改备注会更新回访日期。
- 升级前的旧记录仍可查看摘要、更新六爻回访；当时未保存的完整结果无法补回。
- 保存失败时仍显示当前结果，并提示用户先用海报留存，不会显示为已保存。
- 换设备、清理小程序数据后，记录不会自动迁移或恢复。

主要存储键：

| 键 | 用途 |
| --- | --- |
| `fortune-history` | 历史摘要、完整结果、回访状态及备注 |
| `fortune-daily-lot` | 当天固定签文缓存，与历史记录分开保存 |
| `fortune-account-state` | 本地存储状态展示 |
| `fortune-pending-yao-intent` | 首页预设问题跳转到问事页 |
| `fortune-pending-record-id` | 从首页或记录页跳转到原六爻结果 |

分享小程序卡片用于邀请朋友体验；本机记录不通过链接传给其他设备。要分享当时的结果，请使用海报。

## 本地自动检查

安装 Node.js 后，在根目录运行：

```bash
node --test tests/*.test.js
```

检查覆盖每日签日期稳定与去重、逐爻展示与跳过、64卦知识对应、完整结果存储、原结果回看、回访状态与备注、删除、容量确认、历史摘要兼容、保存失败与海报回调。算法与页面代码是真实代码，微信存储、导航、确认弹窗和 Canvas 接口使用测试适配器。

这些检查不能替代微信模拟器、真机画面与相册授权的验收。

## 微信环境验收

1. 从首页分别进入抽签、六爻问事，生成结果。
2. 确认先展示简明结果，详细内容可以展开和收起。
3. 在记录页回看完整结果，与生成时一致。
4. 关闭小程序再打开，确认记录和完整结果仍能回看。
5. 从六爻结果页更新回访，再到记录页确认状态一致；反向更新后也应一致。
6. 对新结果和历史结果分别生成海报，确认内容正确，图片可保存到相册。
7. 拒绝相册授权时确认能看到保存失败提示，页面仍可使用。
8. 查看升级前的旧摘要记录，确认不会为了回看而重新起卦。
9. 确认记录列表位于统计前；统计可以展开和收起。
10. 单条删除分别选择取消和确认；确认后其他记录、当前筛选与容量应保持正确。
11. 记录达到18条时出现剩余空间提示；达到20条时取消新增应保留全部记录，确认新增应仅替换提示中的旧记录。
12. 分别从记录页、原卦页添加或修改回访备注，重开后仍能读取；取消编辑不保存，留空保存可清除。
13. 今日一签首次揭签后，返回首页、重新打开、关闭小程序再打开，确认完整签文一致且只占一条记录；删除该历史后仍可读当日签，不恢复历史。
14. 次日返回今日一签，确认显示新日期且可再次揭签；满额时取消首次揭签不生成签文或缓存。
15. 六爻动画确认三枚铜钱和六条爻线由下到上依次出现；跳过后结果一致，记录只保存一次；中途切换页面不产生新记录。
16. 新卦和旧卦均能展开、收起卦象知识，原文与白话标签清楚；结果页生成后收起输入区并回到页面顶部。

## 当前边界

- 内容采用规则与模板组合，以娱乐和自我探索为用途。
- 历法与六爻规则仍属于原型实现，精度和完整性未经过专业校验。
- 默认体验采用本机存储；当前没有跨设备同步或真实支付链路。
- 微信环境的编译、画面和权限行为，需要在微信开发者工具及真机上验证。
