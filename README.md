# 大可不必算

一个原生微信小程序项目，方向是“轻互动占卜 + 个人记录 + 云端同步”。

它不是做成传统工具站那种冷冰冰的排盘器，而是更偏内容体验：用户可以抽签、起六爻、看轻量星盘，把结果留在记录页里，过几天再回来做回访和复盘。

> 当前版本定位：娱乐向传统文化体验产品原型  
> 适用场景：微信小程序 Demo、占卜内容产品 MVP、云开发同步练手项目

## 功能亮点

- `抽签`：按主题和面对方式抽签，生成签文、解释、提醒和行动建议
- `六爻`：支持问题引导、六爻排盘、月建日辰、旬空、伏神、进退神、反吟伏吟、应期提示和分享海报
- `星盘`：录入出生时间与地点，生成轻量星盘、元素分布、宫位重心和人格解读
- `记录页`：保存抽签、六爻和星盘结果，支持筛选、统计、回访和同步状态查看
- `云同步`：支持静默识别当前微信身份、本机与云端快照同步、跨设备拉回、分开清空本机和云端

## 技术实现

- `原生微信小程序`
- `微信云开发`
- `本地存储 + 云端快照同步`
- `内容模板 + 规则生成`

核心思路不是依赖外部 API，而是把内容库、规则引擎和结果展示都放在小程序本地与云开发组合里，先把产品体验跑起来。

## 快速开始

1. 安装并打开微信开发者工具
2. 选择“导入项目”
3. 项目目录选择当前仓库根目录
4. 使用自己的小程序 `AppID` 打开项目
5. 编译并在模拟器或真机预览

当前项目关键配置：

- 小程序配置：[app.json](./app.json)
- 项目配置：[project.config.json](./project.config.json)
- 站点地图：[sitemap.json](./sitemap.json)

## 云开发接入

项目已经接入“静默识别 + 历史快照同步”的正式骨架，但如果你要在自己的账号下运行，建议把云环境改成你自己的。

### 1. 修改云环境 ID

在 [utils/cloud.js](./utils/cloud.js) 里，把 `CLOUD_ENV_ID` 替换成你自己的云开发环境 ID。

### 2. 开通云开发环境

在微信开发者工具或微信云开发控制台中，创建并绑定当前小程序使用的云开发环境。

### 3. 部署云函数

需要部署这两个云函数：

- [cloudfunctions/account/index.js](./cloudfunctions/account/index.js)
- [cloudfunctions/historySync/index.js](./cloudfunctions/historySync/index.js)

在微信开发者工具中分别右键目录：

- `cloudfunctions/account`
- `cloudfunctions/historySync`

选择“上传并部署：云端安装依赖”。

### 4. 确认数据库集合

云函数会使用这两个集合：

- `fortune_users`
- `fortune_history_snapshots`

### 5. 回到“记录”页验证同步状态

部署完成后，进入“记录”页，检查：

- 是否能识别账号
- 是否能读取云端记录数
- 是否能执行“立即同步 / 从云端拉回 / 清空本机 / 清空云端 / 恢复云端备份”

## 同步策略说明

为了避免误操作，这个项目把“清空本机”和“清空云端”做成了两条完全不同的链路。

- `立即同步`：把当前设备记录与云端快照对齐
- `从云端拉回`：把云端历史拉回当前设备
- `清空本机`：只清空当前设备，不动云端，而且不会自动回灌
- `清空云端`：只清空云端备份，本机记录保留
- `恢复云端备份`：在清空云端后，手动把本机记录重新上传为新的备份

这套状态机的核心逻辑在：

- [utils/history-sync.js](./utils/history-sync.js)
- [utils/history.js](./utils/history.js)
- [utils/cloud.js](./utils/cloud.js)
