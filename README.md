# 大可不必算

一个原生微信小程序项目，方向是“轻互动占卜 + 个人记录 + 本地存储”。

它不是做成传统工具站那种冷冰冰的排盘器，而是更偏内容体验：用户可以抽签、起六爻、看轻量星盘，把结果留在记录页里，过几天再回来做回访和复盘。

> 当前版本定位：娱乐向传统文化体验产品原型
> 适用场景：微信小程序 Demo、占卜内容产品 MVP、本地存储体验原型

## 功能亮点

- `抽签`：按主题和面对方式抽签，生成签文、解释、提醒和行动建议
- `六爻`：支持问题引导、六爻排盘、月建日辰、旬空、伏神、进退神、反吟伏吟、应期提示和分享海报
- `星盘`：录入出生时间与地点，生成轻量星盘、元素分布、宫位重心和人格解读
- `记录页`：保存抽签、六爻和星盘结果，支持筛选、统计、回访和本地存储说明
- `本地存储`：结果直接保存在当前设备，不依赖云开发和云函数

## 技术实现

- `原生微信小程序`
- `微信小程序本地存储（wx.setStorageSync / wx.getStorageSync）`
- `内容模板 + 规则生成`

核心思路不是依赖外部 API，而是把内容库、规则引擎、结果展示和记录能力都放在小程序本地，先把产品体验跑起来。

## 快速开始

1. 安装并打开微信开发者工具
2. 选择“导入项目”
3. 项目目录选择当前仓库根目录
4. 使用自己的小程序 `AppID` 打开项目
5. 编译并在模拟器或真机预览

当前项目关键配置：

- 小程序配置：[app.json](./app.json)

## 本地存储说明

当前版本默认把数据直接写入微信小程序本地存储，不再依赖云开发环境。

主要使用的本地存储键：

- `fortune-history`：历史记录
- `fortune-account-state`：记录页展示用的本地状态
- `chart-profile`：星盘页最近一次填写的出生信息
- `fortune-pending-yao-intent`：从首页跳转到问事页时的临时意图

当前行为：

- 新生成的抽签、六爻、星盘记录会直接写入本地
- 六爻回访状态修改后会直接写回本地
- 记录页清空的是当前设备上的本地数据
- 换设备、清理小程序缓存或删除小程序数据后，历史不会自动恢复

仓库中保留了 `cloudfunctions` 目录，但当前默认流程不会使用它。

## 本地记录策略

- `创建结果`：立即写入本地存储
- `回访更新`：直接覆盖对应历史记录
- `进入记录页`：从本地存储读取并生成统计信息
- `清空本机`：只清掉当前设备上的历史记录

这部分核心逻辑在：

- [utils/history.js](./utils/history.js)
- [utils/history-sync.js](./utils/history-sync.js)
- [utils/cloud.js](./utils/cloud.js)

## 注意事项

- 本项目当前以 `微信开发者工具` 为主，不是标准 npm Web 项目
- 部分功能依赖微信环境，不能仅靠 Node 在本地完整运行
- 当前默认只使用本地存储，不提供跨设备同步
- 占卜、运势、星盘相关内容建议以“娱乐参考 / 传统文化体验”语境呈现
